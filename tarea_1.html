Parte 1: Manipulación de Tablas

En esta primera parte trabajaremos con la base de datos del Servicio de Impuestos Internos (SII) a nivel nacional. El conjunto de datos representa la cantidad de metros cuadrados construidos por manzana en Chile, clasificados por uso (comercio, oficinas, vivienda).

Insumo:

# Cargar librerías necesarias
library(dplyr)    # Manipulación de tablas
library(sf)       # Manipulación de datos espaciales
library(ggplot2)  # Gráficos de alto nivel

# Leer datos del SII
tbl_sii <- readRDS("data/sii/mz_constru_SII.rds") %>% 
  st_drop_geometry()  # Usaremos solo la tabla, sin geometría

Instrucciones de la tarea:

  • Importante: Sigue los pasos en orden y asegúrate de que tu código sea reproducible. Usa nombres de variables claros.
  1. Función para calcular proporciones (1 punto)
    • Crea una función propia en R que reciba como argumentos:
      • El valor de una categoría (por ejemplo, m² de comercio).
      • El valor total de m² construidos.
    • La función debe devolver la proporción (en decimal o porcentaje) de la categoría respecto al total.
    • (Referencia: Crear Funciones Propias).
  2. Aplicación de la función (1 punto)
    • Utiliza la función creada en el paso anterior para calcular, para cada manzana, las proporciones de:
      • m² de Comercio
      • m² de Oficinas
      • m² de Vivienda
    • Guarda estos nuevos valores como columnas adicionales en tbl_sii. (Referencia: Mutate).
  3. Análisis por región (1 punto)
    • Selecciona una región de Chile (a tu elección).
    • Calcula, para cada comuna de esa región, el promedio de las proporciones de m² de Comercio, Oficinas y Vivienda obtenidas en el paso anterior.
    • Presenta los resultados en una tabla resumen.
    • Genera un gráfico de barras que compare estos promedios por comuna de una categoría solamente (por ejemplo Oficinas).
    • (Referencias: Resúmenes Estadísticos, Gráficos de Barra con ggplot2).

Parte 2: Manipulación de Vectores Espaciales

En esta segunda parte trabajaremos con los polígonos de zonas censales del INE, que servirán para realizar operaciones espaciales.

Insumo:

# Cargar Librerías
library(dplyr) # Manipulación de tablas
library(sf) # Manipulación de datos espaciales
library(ggplot2) # Generar gráficas de alto nivel


# zonas censales INE, seleccionará columnas de interés
zonas_censales <-  readRDS("data/censo/zonas_urb_consolidadas.rds") %>% 
  select(REGION, NOM_REGION, COMUNA, NOM_COMUNA, COD_INE_16, ESC_JH, PERS)

Siga los pasos en orden. Usa nombres de variables claros y agrega comentarios a tu código para explicar cada operación.

  1. Filtrar comunas seleccionadas (1 punto)

    • Elige dos o más comunas contiguas dentro de una misma región.
    • Filtra la base de zonas censales utilizando la columna NOM_COMUNA para quedarte únicamente con esas comunas seleccionadas. Filtros y selección de columnas
    • Guarda el resultado en un nuevo objeto.

  2. Cálculo de área y densidad de población (1 punto)

    • Calcula una nueva variable AREA_HA que represente el área de cada polígono en hectáreas (st_area(.) / 10000). Referencias Generación columnas.
    • Calcula la densidad de población (PERS / AREA_HA).
    • Genera dos mapas con ggplot2:
      • Población absoluta (PERS por zona censal).
      • Densidad de población (personas por hectárea).
    • Usa escalas de color adecuadas y leyendas claras para cada mapa.

  3. Promedio comunal de escolaridad y análisis espacial (1 punto)

    • Calcula, a nivel comunal, el promedio de escolaridad del jefe/a de hogar (ESC_JH) usando group_by() y summarise() (Referencia: Resumen Estadísticos Espaciales).
    • Une esta tabla resumen a la base espacial filtrada en el punto 1 mediante left_join() (Referencia: Joining).
    • Calcula una nueva variable que represente la diferencia entre:
      • La escolaridad de cada zona censal (ESC_JH), y El promedio comunal calculado previamente.
    • Genera un mapa temático mostrando esta diferencia y analiza si existe algún patrón espacial visible.
