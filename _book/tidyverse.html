4  Manipulación de tablas en R

Manipulación de Tablas utilizando dplyr

Objetivo de esta sección

Conocer el conjunto de paquetes tidyverse y utilizar dplyr para explorar, seleccionar, filtrar, resumir y transformar tablas de datos. Estas operaciones permiten preparar información territorial para construir indicadores y apoyar decisiones de política pública.

4.1 Introducción: de los registros a la evidencia territorial

En el trabajo con políticas públicas, los datos rara vez llegan listos para responder una pregunta. Una base puede contener miles de registros de manzanas, personas, establecimientos o eventos, junto con columnas que no son necesarias para el análisis. Antes de elaborar un mapa, un gráfico o un indicador, es necesario organizar esa información y definir con transparencia qué se incluye, qué se excluye y cómo se calcula cada resultado.

Por ejemplo, una institución podría contar con registros de atenciones de salud para todo un año. Para responder “¿en qué comunas se concentra la demanda?” no basta con abrir la planilla: habría que seleccionar las variables pertinentes, filtrar el periodo de interés, agrupar los registros por comuna y construir un resumen o una tasa comparable. En este capítulo se practica esa misma lógica con una base de manzanas del Servicio de Impuestos Internos (SII).

El tidyverse ofrece un lenguaje consistente para realizar estas tareas en R. Trabajar con instrucciones escritas en un script tiene una ventaja importante: el procedimiento queda documentado y puede repetirse cuando se reciben datos nuevos, se corrige una fuente o se necesita revisar una decisión. La reproducibilidad no reemplaza el juicio profesional; sí permite que las reglas de análisis sean visibles, discutibles y menos propensas a errores manuales.

Una pregunta guía el flujo de trabajo

Antes de manipular una tabla, formule una pregunta concreta. Por ejemplo: “¿qué comunas tienen mayor proporción de superficie destinada a comercio?” o “¿qué manzanas combinan vivienda y comercio?”. La pregunta define la unidad de análisis, las variables necesarias y el tipo de indicador. También ayuda a evitar comparar totales entre territorios de tamaños muy distintos cuando una tasa o proporción sería más apropiada.

4.1.1 Ruta de análisis que se practicará

Las funciones de dplyr se pueden entender como una secuencia de decisiones sobre una tabla:

  • select() define las columnas que se conservarán para el análisis.
  • filter() mantiene los registros que cumplen una condición explícita.
  • group_by() establece la unidad para resumir, por ejemplo, comuna o región.
  • summarise() calcula medidas agregadas para cada grupo.
  • mutate() crea indicadores o categorías nuevas a partir de las variables disponibles.

Estas operaciones se pueden encadenar con el operador pipe (%>%), que se lee de arriba hacia abajo: tomar una tabla, aplicar un paso y usar el resultado en el paso siguiente. Más que memorizar comandos, procure explicar con sus propias palabras qué decisión representa cada línea y revisar el resultado después de cada transformación.

4.2 Introducción a tidyverse

Tidyverse es una colección de paquetes diseñados para Ciencia de Datos.

# instalación
install.packages("tidyverse")

Todos los paquetes comparten una filosofía de diseño, una gramática y estructuras de datos.

Esta filosofía promueve

  • En Pipes, navegarás dentro del pipe, %>%, para anidar instrucciones
  • Si bien copiar-y-pegar (copy-and-paste) es una herramienta poderosa, deberías evitar utilizarla más de dos veces. Repetir el código es peligroso porque puede llevar a errores e inconsistencias.
  • Las funciones nos permiten evitar la repetición de código.

4.4 Funciones básicas dplyr

4.4.1 Select

La función select() de dplyr permite elegir columnas específicas de un dataframe. Es muy útil para reducir la tabla de trabajo a las variables que realmente necesitas, facilitando el análisis y la legibilidad del código.

Puedes usarla para:

  • Conservar solo algunas variables,
  • Eliminar columnas que no son necesarias, o
  • Reordenar el orden de las columnas.

Ejemplo básico

Este código creará una nueva tabla con solo las columnas n_com, manzana, oficinas y comercio.

# seleccionar nombres de columnas que deseo conservar
tbl_sii %>%
  select(n_com, oficinas, comercio, vivienda)

Estos casos los puedes revisar en el siguiente tip:

Diferentes Tipos de Selecciones
  • : para seleccionar un rango de variables consecutivas.
  • ! para tomar el complemento de un conjunto de variables.
  • & y | para seleccionar la intersección o la unión de dos conjuntos de variables.
  • c() para combinar múltiples selecciones.

Además, puedes utilizar funciones auxiliares de selección (selection helpers). Algunas seleccionan columnas específicas:

  • everything(): Selecciona todas las variables.
  • last_col(): Selecciona la última variable (con opción de desplazamiento).
  • group_cols(): Selecciona todas las columnas utilizadas para agrupar.

Otras seleccionan variables por patrones en sus nombres:

  • starts_with(): Comienza con un prefijo.
  • ends_with(): Termina con un sufijo.
  • contains(): Contiene una cadena de texto literal.
  • matches(): Coincide con una expresión regular.
  • num_range(): Coincide con un rango numérico como x01, x02, x03.

También puedes seleccionar a partir de nombres guardados en un vector de caracteres:

  • all_of(): Coincide con todos los nombres del vector. Si alguno no existe, lanza un error.
  • any_of(): Coincide con cualquier nombre del vector. Si alguno no existe, no lanza error.

Finalmente, puedes usar funciones lógicas:

  • where(): Aplica una función a todas las variables y selecciona aquellas para las que la función retorna TRUE.

Referencias: https://dplyr.tidyverse.org/reference/select.html

4.4.2 Filter

La función filter() permite seleccionar filas de un dataframe que cumplen con una o más condiciones lógicas. Es muy útil para quedarte solo con los registros relevantes según un criterio territorial, como una comuna específica, superficies mayores a cierto umbral, o zonas de uso mixto.

  1. Filtrar los registros de la comuna de “LAS CONDES”
mi_comuna <- "LAS CONDES" 

sii_com <- tbl_sii %>%
  filter(n_com == mi_comuna)

4.5 Resúmenes Estadísticos

La función group_by() permite agrupar los datos por una o más variables categóricas para aplicar funciones de resumen sobre cada grupo. Es especialmente útil cuando se quiere analizar indicadores por comuna, región, o cualquier otra unidad territorial. En excel sería como las tablas dinámicas.

Por sí sola, group_by() no transforma los datos, pero modifica la forma en que se aplican otras funciones como summarise(), mutate(), o filter(), permitiendo que actúen por grupo en lugar de sobre toda la tabla.

Por ejemplo:

Supongamos que queremos saber cuántos metros cuadrados de oficinas hay por comuna:

  • group_by(n_com) agrupa la tabla por comuna.
  • summarise() calcula el total de oficinas por cada grupo (comuna).
tbl_resumen <-  tbl_sii %>%
  group_by(n_com) %>%
  summarise(total_oficinas = sum(oficinas, na.rm = TRUE)) %>% 
  arrange(desc(total_oficinas)) # Ordenar

¿Qué ocurre internamente?

Después de aplicar group_by(), las funciones que siguen operan por separado en cada grupo. Esto permite realizar cálculos agregados, densidades por unidad territorial, o resúmenes diferenciados fácilmente.

Recuerda siempre cerrar los bloques agrupados cuando termines, si vas a seguir operando fuera del contexto del grupo. Puedes usar ungroup() si es necesario.

Referencias: https://dplyr.tidyverse.org/reference/group_by.html

Hint: Densidad de comercio, se puede entender como la división de la cantidad de metros cuadrados de comercio dividido por el total de metros cuadrados.

4.6 Mutate

La función mutate() de dplyr permite crear nuevas columnas o modificar columnas existentes dentro de un dataframe, utilizando expresiones que pueden depender de otras variables del mismo dataframe.

Es una herramienta clave para transformar datos territoriales, por ejemplo, al calcular proporciones, densidades o indicadores derivados.

Note

Sintaxis básica:

data %>%
  mutate(nueva_variable = expresión)

Ejemplos con tbl_sii

  1. Crear proporción de oficinas sobre el total construido
tbl_sii <- tbl_sii %>%
  mutate(prop_oficinas = (oficinas / total) * 100)

Tips: mutate()
  • Puedes crear varias variables a la vez dentro de un solo mutate().
  • Las nuevas variables pueden depender de otras que acabas de crear en la misma llamada a mutate().
  • Si una expresión contiene NA, puedes agregar na.rm = TRUE dentro de funciones como sum(), mean(), etc., aunque no dentro de mutate() directamente.
