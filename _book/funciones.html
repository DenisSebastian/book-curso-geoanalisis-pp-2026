3.1 Introducción: funciones para un análisis reproducible

En este curso, programar no es un fin en sí mismo: es una forma de convertir preguntas sobre el territorio en procedimientos claros, revisables y reutilizables. Una función es una instrucción que recibe uno o más datos, realiza una tarea y devuelve un resultado. R ya incluye muchas funciones —por ejemplo, mean() para calcular un promedio o max() para encontrar el valor más alto— y también permite crear funciones propias cuando una tarea se repite.

Esta idea es especialmente útil en políticas públicas. Suponga que necesita calcular una tasa de delitos, clasificar el nivel de vulnerabilidad de cada comuna o verificar que un indicador no tenga valores faltantes. Puede hacer cada cálculo manualmente una vez; sin embargo, una función permite aplicar la misma regla a todas las comunas, periodos o bases de datos. Así se reducen errores, se hace explícito cómo se construyó un resultado y se facilita que otra persona revise o actualice el análisis.

Una manera simple de pensar una función es como una receta:

  • Entrada: los datos que necesita, por ejemplo, casos policiales y población comunal.
  • Regla: el cálculo o criterio que se aplicará, por ejemplo, dividir los casos por la población y multiplicar por 100.000.
  • Salida: el resultado que se usará para analizar o comunicar, por ejemplo, una tasa comparable entre comunas.

No es necesario memorizar todas las funciones de R. Lo importante al comienzo es reconocer qué problema se quiere resolver, identificar qué información debe entrar y comprobar que el resultado tenga sentido. En este capítulo se practican operaciones, resúmenes y condiciones que luego se utilizarán para manipular tablas, construir indicadores territoriales y generar visualizaciones.

Conexión con las políticas públicas

Las funciones ayudan a que una decisión basada en datos sea más trazable. Si un municipio prioriza comunas según una tasa, la función permite conservar la regla de cálculo junto con el análisis. Al recibir datos de un nuevo mes o año, se puede ejecutar nuevamente el mismo procedimiento en vez de reconstruir el indicador desde cero. Reproducir no garantiza por sí solo una buena decisión: también es necesario revisar la calidad de los datos, el periodo, la población de referencia y el contexto territorial.

3.1.1 Ruta de aprendizaje del capítulo

El capítulo avanza desde operaciones sencillas hacia funciones propias. Primero se revisan cálculos y resúmenes de vectores; después, funciones para repetir, secuenciar y clasificar información; finalmente, se crean funciones que encapsulan una tarea y permiten reutilizarla. Cada paso prepara habilidades que se ocuparán en las sesiones de manipulación de datos, visualización y análisis espacial.

3.2 Operaciones Básicas en R

3.2.1 Operaciones Matemáticas

En R, es posible realizar operaciones matemáticas básicas utilizando los operadores aritméticos estándar. Estos operadores incluyen:

  • Suma (+): se utiliza para sumar dos valores.
  • Resta (-): se utiliza para restar un valor de otro.
  • Multiplicación (*): se utiliza para multiplicar dos valores.
  • División (/): se utiliza para dividir un valor por otro.
  • Exponenciación (^): se utiliza para elevar un valor a una potencia.
  • Módulo (%%): se utiliza para encontrar el resto de la división de un valor por otro.

Estos operadores se pueden utilizar con números enteros, decimales y variables numéricas. Además, también se pueden utilizar paréntesis para especificar el orden de las operaciones.

A continuación, se presentan algunos ejemplos de operaciones matemáticas básicas en R:

# Suma
2 + 3 # resultado: 5
[1] 5
# Resta
5 - 2 # resultado: 3
[1] 3
# Multiplicación
2 * 4 # resultado: 8
[1] 8
# División
10 / 2 # resultado: 5
[1] 5
# Exponenciación
2^3 # resultado: 8
[1] 8
# Módulo
15 %% 4 # resultado: 3
[1] 3
# Utilizando paréntesis para especificar el orden de las operaciones
(2 + 3) * 4 # resultado: 20
[1] 20

Es importante tener en cuenta que R sigue las reglas de precedencia de las operaciones matemáticas. Esto significa que las operaciones dentro de los paréntesis se evalúan primero, seguidas de la exponenciación, la multiplicación y la división, y finalmente la suma y la resta. Si se requiere un orden específico de operaciones, se deben utilizar paréntesis para indicarlo.

3.4.3 Funciones de Condiconales

La función ifelse() permite evaluar una condición lógica y devolver un resultado distinto según se cumpla o no. Es una herramienta muy útil para tomar decisiones dentro de un vector.

Su estructura general es:

ifelse(condición, valor_si_verdadero, valor_si_falso)
  • La condición se evalúa para cada elemento del vector.
  • Si se cumple (TRUE), devuelve el segundo argumento.
  • Si no se cumple (FALSE), devuelve el tercero.

Por ejemplo:

# Notas de un alumno
notas <- c(6.5, 3.5, 5.0, 2.0, 7.0)

# Evaluar Condición y categorizar
ifelse(notas >= 4.0, "Aprobado", "Reprobado")
[1] "Aprobado"  "Reprobado" "Aprobado"  "Reprobado" "Aprobado"

3.5 Crear Funciones Propias

En R, es posible crear funciones propias para realizar tareas específicas y reutilizarlas en diferentes partes de un programa.

¿Por qué crear funciones?

Crear funciones propias te permite automatizar tareas, evitar repetir código y estructurar tu análisis de manera más clara y reutilizable.

Para crear una función en R, se utiliza la siguiente estructura:

nombre_de_la_funcion <- function(argumentos) {
  cuerpo_de_la_funcion
}

Por ejemplo, se puede crear una función que calcule la suma de dos números:

suma <- function(a, b) {
  resultado <- a + b
  return(resultado)
}

resultado_suma <- suma(2, 3)
print(resultado_suma) # 5
[1] 5
  • En R, la última línea de una función se retorna automáticamente, pero usar return() hace explícito qué quieres devolver, lo cual mejora la legibilidad.

Por ejemplo, se puede crear una función que eleve al cuadrado un número dado:

cuadrado <- function(x) { # x = parámetro
    y = x ^ 2 # asiganción de variables solo dentro de la función
    return(y) # especificar valor retornado (no necesario completamente)
}
a <- 13
cuadrado(a)
[1] 169
b <- c(20,30,22,2,1)
cuadrado(b)
[1] 400 900 484   4   1

Funciones con Parámetros por defecto

Es posible usar funciones con valores por defecto en sus argumentos

cuadrado <- function(x = 2) { # x = parámetro con valor por defecto
    y = x ^ 2 # asiganción de variables solo dentro de la función
    return(y) # especificar valor retornado (no necesario completamente)
}
cuadrado()
[1] 4
cuadrado(x = 3)
[1] 9

Anidar Funciones

doble_cuadrado <- function(x) {
  cuadrado(x * 2)
}
doble_cuadrado(3)  # (3*2)^2 = 36
[1] 36

Es importante tener en cuenta que los nombres de las funciones en R deben cumplir las mismas reglas que los nombres de las variables. Además, es recomendable incluir comentarios explicativos dentro del cuerpo de la función para facilitar su comprensión y uso posterior.
